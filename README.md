# منصة الاختبارات التشخيصية

واجهة منصة اختبارات العلوم المتكاملة — الصف الأول الثانوي.

## ما يحويه هذا المستودع

ملف `index.html` فقط: الواجهة التي يراها الطالب والمعلم.

**لا يحوي أي سؤال أو إجابة.** كل المحتوى يُسحب من Supabase وقت التشغيل،
وسياسات RLS تحكم من يرى ماذا. لهذا فنشره علناً آمن تماماً.

## البنية

```
المتصفح  ──►  Supabase
              PostgreSQL · Auth · RLS
```

## التشغيل محلياً

افتح `index.html` مباشرة في المتصفح. يتصل بنفس قاعدة البيانات.

## المفاتيح

`SUPABASE_ANON` مفتاح عام (publishable) مصمَّم للكشف في المتصفح.
الحماية تأتي من سياسات RLS لا من إخفائه.

المفتاح السري (`service_role`) **لا يوجد في هذا المستودع ولن يوجد**.

## المحتوى والأسئلة

في مستودع منفصل خاص: `quiz-content`
