# محاكاةُ محطّات اختبار تحديد المستوى — دليلُ ق١٧

> **لماذا هنا:** القرارُ ق١٧ (`spec-reading-library.md` §٤) بُني على هذه الأرقام، فتبقى معه. **وهي إرشادٌ لا تنبؤ** — كما قال مخطّطُ المشروع عن محاكاته (§9.3).

**الافتراضاتُ افتراضاتُ مخطّط المشروع نفسُها** (`Reading project/05-assessment/test-blueprint.md` §9 و`simulation/sim_design2.py`):
النطاقاتُ ٠٫٤ لوجيت · انتشارُ صعوبة البند حول نطاقه ٠٫٥ · أثرُ النصّ ٠٫٣ · معيارُ ٧٥٪ · نصفُ البنود اختيارٌ من متعدّد بتخمين (ثلاثةُ خيارات إلى R8 وأربعةٌ بعدها)
والباقي ٥٪. **والفرق:** لا موجِّهَ من قائمة كلمات — المحطّةُ الأولى توجّه — ومحطّاتٌ من ثلاثة مقتطفاتٍ بثلاثة أسئلة، **وكلُّ قاعدة حسمٍ تُحسب في القاعدة بلا معايرة.**

| السكربت | ما يقيسه |
|---|---|
| `sim_stations.py` | ستّةُ تصاميم: نطاقٌ في المحطّة بقاعدة ٧/٩ · ثلاثةُ نطاقاتٍ بمجموع المحطّة («أدناها» أو «أوسطها») · ثلاثةُ نطاقاتٍ بالتقدير (محطّتان أو ثلاث) · هجين. لطلاب M4 الواقعيّين (حول R13) والمنتشرين، ولـM2 — ومعه «خفضُ نطاقٍ عند الحسم» والاتّساقُ بين جلستين |
| `sim_stations2.py` | الضوابط: **نطاقٌ واحدٌ بالتقدير** (هل الفرقُ من التكوين أم من القاعدة؟) · قاعدة ٨/٩ · سؤالان لكلّ نصّ · محطّةٌ رابعة · مسافةُ النطاقات ٠٫٣ و٠٫٥ |
| `sim_floor.py` | سؤالُ المالك: **دخولٌ عند R18–R20 وطالبٌ ضعيف** — خطوةٌ ثابتة · تقديرٌ أوّليُّه الدخول · تقديرٌ أوّليُّه الطبقة · وقاعدةُ الأرضيّة |

**التشغيل** (Python 3 وnumpy · دقائق):

```
set PYTHONIOENCODING=utf-8
python sim_stations.py  > results_stations.txt
python sim_stations2.py > results_controls.txt
python sim_floor.py     > results_floor.txt
```

**الخلاصة** (التفصيلُ في ق١٧): **تكوينُ المحطّة لا يغيّر الدقّة — قاعدةُ الحسم هي التي تغيّرها.** التقديرُ من المسار كلِّه ٧٤٪ ضمن نطاقٍ و١٢٪ أعلى بنطاقين؛
وقواعدُ العدّ ترفع التسكين (حتى ٥١٪ أعلى بنطاقين). **والتقديرُ يبدأ من الطبقة لا من الدخول**، وإلا سُكّن الضعيفُ الداخلُ من بعيدٍ أعلى من حقّه.
