# tools/ — أدواتُ قناة المحتوى

ثلاثةُ ملفّاتٍ تخدم الدورةَ بين مشروع بيان ومشاريع معلّمي المواد. وعلّةُ وجودها
واحدة: **ما يُكتب بيدٍ في كلّ مرة يُكتب خطأً مرّة.**

| | |
|---|---|
| `state.sql` | يُنتج `bayan-content/state/courses.json`. يُشغَّل **بعد كل استيراد**، فتعود الأرقامُ الجديدة إلى معلّمي المواد |
| `check_map.py` | يفحص ملفّ المرحلة ① آلياً قبل أن يلمس القاعدة. `--state` يفتح أخطرَ الفحوص: مقابلةُ الدروس القائمة والفروع المكتوبة |
| `make_requests.py` | يكتب طلبَ كلّ مقرّر في `bayan-content/requests/`. والطلبُ **لا يحمل حالةً** — المعلّمُ يقرؤها من `courses.json` |
| `notes/<course_id>.txt` | الملاحظةُ التربويّةُ لمنهجٍ بعينه — **الشيءُ الوحيد الذي لا يُشتقّ**، فموضعُه ملفٌّ بيد الإنسان |
| `naqil_cards.gs` | **ناقلُ البطاقات** — Apps Script يطوف مجلدَ `cards` في Drive كلَّ ساعة: يرفع وسائطَ كلِّ ملفٍّ ويكتب مفاتيحَها، ثمّ جافّةٌ ثمّ اعتمادٌ عبر `import_cards`. والتقريرُ بريد |
| `icon_cutout.py` | يقصّ صورةَ مادةٍ مولَّدة على الأبيض إلى ٢٨٠px شفّافة **بلا هالة** (b160). وأوصافُ التوليد وطريقتُه في STATE · b160 |
| `naqil_cards.test.mjs` | قياسُه — `node tools/naqil_cards.test.mjs`. **بلا شبكةٍ ولا Drive ولا قاعدة**: كلُّ طرفٍ خارجيٍّ مُقلَّد |

**الدورة:**

```
state.sql ⇒ courses.json ⇒ make_requests.py ⇒ تُلصق الطلباتُ في مشاريع المواد
                                                        ↓
                      اعتماد ⇐ تجربةٌ جافّة ⇐ check_map.py ⇐ ملفٌّ في maps/
                         ↓
                     state.sql (من جديد) ⇒ المرحلة ②
```

**وناقلُ البطاقات ليس من الدورة أعلاه** — تلك دورةُ **بناء المنهج** (دروسٌ
وفروعٌ وأهداف)، وهذا يملأ **معجمَ المادّة** بعدها. ويسكن هنا لا في مكانٍ آخر
لعلّةٍ واحدة: **ملفٌّ يعيش في Apps Script وحدَه لا تاريخَ له ولا مراجع.**

```
D:\LMS\bayan-content\cards\<المادة>\*.json  (+ الصورُ والأصوات بجوارها)
        ↓  مرآةٌ في Drive
   naqil_cards.gs  ⇒  رفعُ الوسائط ومفاتيحُها  ⇒  جافّة  ⇒  اعتماد
        ↓
   معجمُ المادّة الرسميّ — يبلغ الطالبَ بلا نقرةِ نشر
```

**ويبقى خارج هذه الأدوات ثلاثة، كلُّها بقصد:**

1. **تشغيلُ مشروع المادة** — لا يُؤتمت: قيمةُ ذلك المشروع منهجُه المرفقُ فيه.
2. **الحكمُ على سلامة التقسيم تربوياً** — يقرؤه إنسان، ولا يفحصه سكربت.
3. **الاعتماد** — قرارٌ لا تنفيذ. ومواصفةُ شاشة الاستيراد تقول: «يخرج الوسيطُ
   البشريُّ من حلقة التنفيذ ويبقى في حلقة القرار».
